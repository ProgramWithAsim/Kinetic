Kinetic Settings

Equalizer

Works reliably on your local library songs. Streamed tracks (Discover, country browsing, the extended library) may go silent if you enable a preset and the streaming host doesn't allow audio processing — refresh the page if that happens.

Playback

How search works

Search checks your local library first. On the Discover tab, it also queries the live Audius catalog, broadening the query or showing trending tracks if nothing matches exactly.

Keyboard shortcuts

  • Space — play / pause
  • ← / → — seek back / forward 5s
  • Shift + ← / → — previous / next track
  • ↑ / ↓ — volume up / down
  • M — mute
  • L — like current song
  • S — shuffle
  • R — cycle repeat mode

Data & privacy

Playlists, likes, history and settings are saved only in this browser's local storage. Discover results stream directly from Audius's public catalog.
